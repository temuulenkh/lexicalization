
## Lexicalization project

This repository contains code and data for Khishigsuren, Mollica, Vylomova, and Kemp, Usage frequency predicts lexicalization across languages. 

## Folder structure

#### analysis
This folder contains all of our analysis code.

#### data
This folder contains processed data needed for analyses.

#### output
Figures, tables and results files generated by the analysis scripts.

#### preprocessing
Code for preparing the data.

#### rawdata
This folder contains downloaded data needed for preprocessing and analyses.

## Installing R Libraries 

From within R, run

`> renv::restore()`

to install packages used by the code in this repository.

## Python version

This code was developed using Python 3.11. See `requirements.txt` for a full specification of the environment used.

## Downloading other large files

Large files not uploaded to this repository need to be downloaded from [Zenodo](https://zenodo.org/records/22957480). This folder contains the following files.

  * `doreco` : includes frequency data from DoReCo corpus except for Gurindji and Hoocąk datasets

  * `worldlex` : includes frequency data from Worldlex

  * `clics.sqlite` : includes colexification data from CLICS

  * `swow` : includes word association data from SWOW

  * `wsd_coha.pkl` : includes word sense disambiguation data based on COHA

All files must be placed in  `rawdata` folder to reproduce the analyses.

## Reproducing results

To reproduce tables and figures in main text and supplementary materials, follow the steps below. Gurindji and Hoocąk datasets are not included in the DoReCo files due to copyright reasons. They need to be downloaded from [here](https://doreco.huma-num.fr/languages) and added to the `rawdata/doreco` folder to reproduce the results. 

1) Run `01_prepare_lexicalization.R` in `preprocessing` folder to prepare lexicalization data. The code takes about half an hour to run. Warnings regarding ‘labels without glottocodes’ can be safely ignored. It produces Tables S24-S25 and S28-S29 in the Supplementary Information.

2) Run `02_add_synonyms.ipynb` in `preprocessing` folder to identify candidate synonyms for each concept.

3) Run `03_get_corpus_size.R` in `preprocessing`  folder to get corpus size information for the Worldlex.

4) Run `04_get_context_diversity.R` in `preprocessing` folder to get contextual diversity information from English part of the Worldlex.

5) Run `05_assemble_doreco.R` in `preprocessing` folder to read DoReCo files and combine counts for terms in translation tiers.

6) Run `06_wordnet_lemmas.ipynb` in `preprocessing` folder to prepare a file to lemmatize DoReCo data and terms in other data sets.

7) Run `07_assign_taxonrank.ipynb` in `preprocessing` folder to compute taxonomic depth from WordNet. 

8) Run `08_prepare_predictors.R` in `preprocessing` folder to prepare frequency data and other predictors. It produces Tables S26-S27 in the Supplementary Information.

9) Run `main_analyses.Rmd` in `analysis` folder to run analyses on the relationship between lexicalization and predictor variables as well as part-of-speech analysis. It took about 4 hours to run the code. It produces Figure 2 and Tables 1-2 in the main text, and Tables S1-S2, S7-S14, S17-S20 and Figure S3 in the Supplementary Information.

10) Run `additional_analyses.Rmd` in `analysis` folder  to run analyses on the relationship between lexicalization and the extended set of predictor variables, domain analysis, and analyses on single-language predictors. It produces Tables S3-S6, S15-S16, and Figure S1-S2 in the Supplementary Information.

11) Run `pair_analyses.Rmd` in `analysis` folder  to run analysis of concept pairs and analysis on the relationship between lexicalization and other phenomena. The code takes about 20 minutes to run. It produces Figure 3 in the main text, and Figure S4 and Table S21-S23 in the Supplementary Information.
