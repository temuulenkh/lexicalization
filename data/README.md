
# Data

This folder contains preprocessed data used for our analyses. All files except for `wordnet_mapping_manual.csv`, `synonym_mapping_manual.csv`, and `norare_selected_manual.csv` are generated by scripts in the preprocessing. These three files are created manually.

## Manually created files

`wordnet_mapping_manual.csv` is the manually checked version of `wordnet_mapping.csv`, which is produced by step 1 in the top-level `README.md`; `wordnet_mapping_manual.csv` is then used as input to step 2. `synonym_mapping_manual.csv` is the manually annotated version of `synonym_mapping.csv`, which is produced by step 2; `synonym_mapping_manual.csv` is then used as input to step 8. Both files are already provided in this folder, so this manual annotation step does not need to be repeated to reproduce the results. See the Methods section of the main manuscript for details on the annotation process, and the column descriptions below for each file.

`wordnet_mapping_manual.csv` records our accuracy check of the mappings between Concepticon and WordNet IDs provided in Concepticon 2.6.0: 

* `concepticon_id` : Concepticon ID

* `name` : English lemma provided by Concepticon

* `description` : Definition provided by Concepticon

* `pwn_synset` : WordNet synset ID

* `wordnet_gloss` : English lemma provided by WordNet

* `wordnet_definition` : Definition provided by WordNet

* `synset_validation` : Entered a 1 if the mapping between Concepticon and WordNet ID appears correct, otherwise left blank

* `synset_assignment` : Revised WordNet ID if the mapping between Concepticon and WordNet ID appears incorrect

* `comment` : Comments, if any

`synonym_mapping_manual.csv` contains our manual annotations indicating whether each concept is represented by a lemma or its synonym. See the explanations of columns as follows: 

* `concepticon_id` : Concepticon ID

* `name` : English lemma provided by Concepticon

* `description` : Definition provided by Concepticon

* `final_synset` : WordNet ID associated for the concept (we used revised ID for incorrect mappings)

* `synonym` : Synonym identified using WordNet

* `wordnet_id` : WordNet ID associated for the synonym

* `count` : The number of occurrences of each synonym appears in the word sense disambiguation dataset based on COHA

* `definition` : Definition provided by WordNet for the synonym

* `same_synset` : Entered a 1 if the WordNet ID associated for the concept is the same as the WordNet ID associated for the synonym, otherwise 0

* `annotation` : Entered a 1 if we decide to include the synonym, otherwise 0

* `comment` : Comments if any

`norare_selected_manual.csv` contains our selection of NoRaRe variables that are potentially relevant for explaining lexicalization. See the explanations of columns as follows: 

* `variable_id` : Variable ID as provided in NoRaRe

* `rename` : Our renaming of the variable for simplicity

* `type` : The type of the predictor variable

* `comment` : Information about the measurement
